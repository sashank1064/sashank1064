### 🔭 Featured project — RoboShop

A production-style **11-service e-commerce platform** (Node.js, Java, Python, Go, MongoDB, Redis, MySQL, RabbitMQ, Nginx) deployed four different ways to demonstrate progressive infrastructure maturity:

| Repo | What it demonstrates |
|---|---|
| [`shell-roboshop`](https://github.com/sashank1064/shell-roboshop) | Bash-based bootstrap — the baseline before tooling |
| [`ansible-roboshop`](https://github.com/sashank1064/ansible-roboshop) | Flat Ansible playbooks — idempotent, parameterized |
| [`ansible-roboshop-roles`](https://github.com/sashank1064/ansible-roboshop-roles) | Refactored into proper Ansible roles with `group_vars`, handlers, reusable modules |
| [`terraform`](https://github.com/sashank1064/terraform) | AWS infra: VPC, EC2, ALB, Route 53, IAM, SGs |
| [`terraform-multi-env`](https://github.com/sashank1064/terraform-multi-env) | Same infra, promoted across `dev` / `stage` / `prod` with remote state + workspaces |
